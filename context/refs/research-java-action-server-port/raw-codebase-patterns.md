## Agent: codebase-patterns
Paths relative to kairon/. defs/ = actions/definitions/. U = shared/actions/utils.py.

### Entry and dispatch
- POST /webhook actions/server.py:315-333 -> ActionHandler.process_actions -> ActionProcessor.process_action (processor.py:17-48) -> ActionFactory.get_instance -> execute. Returned slot dict -> [SlotSet]; utterances = responses, slots = events; nothing else emitted.
- Unhandled exception (processor.py:34-48): ActionServerLogs with status="Failed", exception, action, sender, intent, bot, request_id, NO type; failure mail; returns None -> 200 with empty events (action.py:33).
- get_action_type U:507-520: "kairon_voice_disconnect" by name; "utter_" prefix -> kairon_bot_response; else Actions collection status=True.
- Log: ActionServerLogs DynamicDocument (data_objects.py:263-282). Status values shared/data/constant.py:114-118: Success, Failed, Partial_Success, PASSED (actions use Success/Failed only). All actions set user_msg.

### Cross-cutting behaviors
1. Templating (no jinja). prepare_url U:458-492 replaces in order: $SENDER_ID, $INTENT (blank if None), $USER_MESSAGE, then $$name (key vault, blank if missing), then $name for remaining `\$\w+` (slot, blank if None); user message uses kairon_user_msg entity when text starts "/". prepare_response U:648-675 and U:608-645: ${RESPONSE} -> json.dumps(data); ${a.b.0} dotted path (dict key or int list index); dict value json.dumps'd, else str(); raises "Could not find value for keys in response" if response not dict/list; empty template returns raw response. get_parameter_value U:258-288 types: sender_id, slot, user_message, intent, chat_log ({sender_id, session_started, conversation}), key_vault, value; encrypt+value -> decrypt; log masked via get_masked_value. Expression context {"data", "context", "http_status_code", "response_headers"}; compose_response (U:788-806) expression mode calls validate_http_response_status(raise_err=True) first. Confidence high.
2. Pyscript: run_pyscript (U:759-785) POST {source_code, predefined_objects} to async_callback_action.pyscript.url, checks resp["statusCode"]==200, returns resp["body"]; Lambda if evaluator.pyscript.trigger_task. evaluate_pyscript (U:1101-1123) flattens context (data, response_headers, http_status_code); output = bot_response or body or {}; media_ids appended. evaluate_script (U:1086) separate evaluator for form validation: {script, data} -> {success, data}. dynamic_params slots -> filled_slots, then kairon_action_response, http_status_code, then set_slots override. Never in-process. Confidence high.
3. Slots: SlotSet for EVERY key incl None. Most actions set kairon_action_response even if not dispatched; exceptions: slot_set, form_validation, live_agent, callback, schedule, parallel (when not dispatched), two_stage_fallback, voice_disconnect, store_page. filter_out_kairon_system_slots (U:719-724) drops only bot, only on pyscript outputs. fill_slots_from_response (U:809-824) per-slot independent, failure -> None + log, doesn't fail action; time_taken = last slot only. Insertion order matters. Confidence high.
4. Dispatch: handle_utter_bot_response (U:678-685) no-op if falsy; json: parse str then json_message; decode error -> text + log 'Failed to convert http response to json: ...'; text: list -> one per element (dict -> json_message, else text=str). Plain utter_message(bot_response) actions (email, jira, zendesk, pipedrive, hubspot, razorpay, google, web_search, database, schedule, agent, voice_call) send raw text; None -> {"text": None} utterance (unverified). Confidence med-high.
5. Timeouts/retry: action.request_timeout 60s (system.yaml:96, env ACTION_SERVER_REQUEST_TIMEOUT); code default 1s if absent. Async client shared/rest_client.py:51-70: aiohttp_retry ExponentialRetry(attempts=1, statuses={104,502,503,504}) -> effectively none; ClientTimeout(total). execute_request_async SWALLOWS transport exceptions (U:~79-81) -> http_response=None, status_code possibly None; validate_http_response_status ignores falsy status; OK = 200,201,202,204. Sync execute_http_request (hubspot, razorpay, evaluate_script) raises ActionFailure("Failed to execute the url: ...") on non-2xx; adds REQUEST_TIMESTAMP_HEADER; requests params= for GET, json=/data= otherwise. Parallel children: bare aiohttp no timeout. Confidence med-high.
6. Failure: every action logs from finally with Success/Failed; many failures swallowed -> 200 + failure utterance + Failed log. Processor catch-all returns no events and writes own record -> some failures leave two records. trigger_action_failure_mail (U:1140-1156) fire-and-forget asyncio task to support_mail with stack trace, slot values, user_query_history; own failures swallowed. Confidence high.
7. Loopback: parallel_action calls /webhook on itself. prompt_action nests actions in-process; only http, callback, schedule, live_agent, google, agent, parallel expose is_success/response; others AttributeError. Parent log must exist before children. Confidence med.
