## What is solid

- Fernet decrypt verifies the HMAC with `MessageDigest.isEqual` before any AES-CBC work, so there is no padding oracle. It uses a fresh SecureRandom IV per token and the 16/16 signing/encryption split.
- The redirect handler counts hops itself and strips Authorization, Cookie and Proxy-Authorization on any change of scheme, host or port. It keeps one wall-clock deadline across all hops.
- The deferred actions prompt_action and database_action are filtered in ActionFactory and referenced nowhere else. The LLM rephrase path is gone. DATABASE_URL is honoured.
- No `synchronized` block wraps Mongo or SMTP I/O. Locking is only on the in-memory lists of the test catalog.
- The SecretsTest repo scan is meaningful. It requires needles of at least 8 chars and more than 50 files scanned.

Recommendation: REVISE. No blocker reached the shared Mongo data. F-001 to F-005 must be fixed or explicitly waived before Tier 1 is accepted. F-005 in particular blocks any deploy of the compose swap.

Proposed kit updates:
- outbound-clients R1: add "a non-2xx response yields body null and status 500" and "JSON is parsed only for application/json or +json content types; otherwise the body is text" (F-003).
- webhook-contract or templating: add a criterion that `intent` follows rasa_sdk `get_intent_of_latest_message`, with skip_fallback true for context and the catch-all, false for action logs, and None without intent_ranking (F-004).
- templating R8: confirm with a human, or mark it as a deliberate divergence (F-009).
- templating R3: spell out the masking rules: len<=4 fully masked, strategy honoured, unknown strategy fully masked (F-001).
- outbound R8: name storage-backed media fetch, the `media_{id}{ext}` part name and size-limit enforcement as testable criteria (F-002).
